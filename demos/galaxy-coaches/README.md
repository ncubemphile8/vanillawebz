Galaxy Coaches concept website

A responsive demo stored in demos/galaxy-coaches inside the VanillaWebz repository. It includes a six-second photo-animated hero video from user-provided bus references, a Galaxy-inspired livery on a licensed Three.js coach model, working orbit/view controls, route selector and verified official booking/app/support links. The quick-trip widget redirects to the official booking portal; it does not fake live fares or seat availability.

Run npm install then npm run dev. Official site: https://www.galaxycoaches.co.zw/
